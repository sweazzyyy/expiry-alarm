# Будильник сроков (Electron + localStorage)

## Запуск
```
cd D:\alarm
npm install
npm start
```

## Сборка установщика .exe
```
npm run dist
```
Установщик появится в папке `dist`.

## Что умеет
- Будильники: продукт, место, дата/время списания, комментарий, быстрые даты (+1 ч … +7 дней), популярные продукты.
- Озвучка через голоса Windows («Внимание! Истёк срок: … Спишите.»), повтор каждые N секунд, предупреждение за N минут.
- 6 синтезированных сигналов (звонок подачи, кухонный таймер, динь-дон, колокольчик, гонг, мягкий) и свои записи mp3/m4a/wav.
- Системные уведомления, мигание в панели задач, работа из трея (крестик сворачивает), автозапуск с Windows.
- Учёт часов работы: если срок выпадает на закрытое время, будильник переносится на момент закрытия.
- Списание: «истёк срок» / «закончилось раньше» + количество; удаление ошибочных.
- Отчёты за день: раньше срока / вовремя (≤15 мин) / с опозданием / не списано. Хранятся 14 дней.
- Все данные в localStorage, есть экспорт и импорт JSON.
- Ctrl+N — новый будильник. Кнопка «Тишина 5 мин».

Русский голос: Параметры → Время и язык → Речь → Добавить голоса → Русский.
